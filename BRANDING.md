# Temivu identity

The Temivu mark combines a rounded T with a separate mint tile. The mark and
wordmark are original project assets distributed under the [MIT license](LICENSE).

| Asset | Use |
| --- | --- |
| [SVG mark](branding/temivu-mark.svg) | Primary mark at any size |
| [PNG mark](branding/temivu-mark-512.png) | Raster avatar or application icon |
| [SVG lockup](branding/temivu-lockup.svg) | Mark and wordmark on light surfaces |

The primary mark uses charcoal `#151B18`, off-white `#F7FAF8` and mint
`#8FE3BE`. Earlier logo assets remain in [branding](branding/) for existing uses.
